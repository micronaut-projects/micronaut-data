Micronaut Data JDBC / R2DBC supports building queries programmatically at runtime using the Jakarta Persistence Criteria API. The repository interfaces, the specification types and how to use them for querying, updating and deleting are the same for all Micronaut Data modules and are described in the <<criteriaSpecifications, Repositories with Jakarta Criteria API>> section.

Micronaut Criteria API for JDBC / R2DBC currently implements only a subset of the API.

To use Jakarta Criteria API you need to add an optional dependency:

dependency:jakarta.persistence:jakarta.persistence-api[]

Then extend api:data.repository.jpa.JpaSpecificationExecutor[] (or one of its <<otherRepositoryVariations, variations>>) in a ann:data.jdbc.annotation.JdbcRepository[] or ann:data.r2dbc.annotation.R2dbcRepository[] repository:

snippet::example.PersonRepository[project-base="doc-examples/jdbc-example",source="main" tags="repository",indent="0"]

Currently, not supported JPA Criteria API features:

- Joins with custom `ON` expressions
- Operators dealing with an entity type and casting
- Collection operations: `isMember` etc
- Transformation expressions like toString, substring etc.
- Cases

More information about Jakarta Persistence Criteria API 3.0 you can find at the https://jakarta.ee/specifications/persistence/3.0/jakarta-persistence-spec-3.0.html#a6925[official API specification]
