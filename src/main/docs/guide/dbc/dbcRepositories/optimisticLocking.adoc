Optimistic locking is a strategy where you note the actual record state's version and modify the record only when the version is the same.

To enable optimistic locking for your entity add ann:data.annotation.Version[] annotated field with one of the types:

- `java.lang.Integer`
- `java.lang.Long`
- `java.lang.Short`
- Date-time type extending `java.time.Temporal`

The field is going to be incremented (for number types) or replaced (for date types) on an update operation.

Micronaut Data will generate `UPDATE`/`DELETE` SQL queries with a version match: `... WHERE rec.version = :currentVersion ...` and if the update/delete doesn't produce any result api:data.exceptions.OptimisticLockException[] will be thrown.

It's possible to use ann:data.annotation.Version[] in a partial update or a delete method, in this case the version needs to match the version of the stored record.

For SQL dialects, you can also compute optimistic locking values with ann:io.micronaut.data.annotation.sql.GeneratedETag[], ann:io.micronaut.data.annotation.sql.ETagValue[], and ann:io.micronaut.data.annotation.sql.ETaggable[].
Annotate a `String` version property with `@GeneratedETag`, mark individual input fields with `@ETagValue`, or annotate the entity with `@ETaggable` to include all eligible persistent scalar fields by default.
Use `@ETagValue(exclude = true)` to exclude a field from class-level `@ETaggable` input selection.
Owning-side foreign-key columns are included only when `@ETaggable(includeForeignKeys = true)` is set or when the relation property is explicitly annotated with `@ETagValue`.

[source,java]
----
@MappedEntity
@ETaggable
class Book {
    @Id
    Long id;

    @ETagValue(exclude = true)
    String notes;

    @GeneratedETag
    String etag;
}
----

When `function` is omitted on `@GeneratedETag`, Micronaut Data resolves it from the SQL dialect at query-build time. Oracle defaults to `SYS_ROW_ETAG`; for other dialects you must provide an explicit function value.
The `function` value should be a function name or schema-qualified function name only; do not include parentheses, argument placeholders, or column references because Micronaut Data supplies the resolved ETag input columns.
