The `micronaut-data-neo4j` module runs Cypher with the https://neo4j.com/docs/java-manual/current/[Neo4j Java driver], whose `Driver` bean comes from https://micronaut-projects.github.io/micronaut-neo4j/latest/guide/[Micronaut Neo4j].

dependency:io.micronaut.data:micronaut-data-neo4j[]

Repositories are annotated with ann:data.neo4j.annotation.Neo4jRepository[].

Each operation runs in the Neo4j transaction of the current Micronaut transaction, started with `@Transactional` or api:data.neo4j.transaction.Neo4jTransactionOperations[]. Without one, each operation runs as an auto-commit query in a session opened for it.

<<graphReactive, Reactive repositories>> run on the reactive sessions of the driver, in the transaction started by a reactive `@Transactional` method or api:data.neo4j.transaction.Neo4jReactorTransactionOperations[]. The database defaults to the default database of the server, `micronaut.data.neo4j.database` selects another.

Identifiers generated by Neo4j are element identifiers when the identity is a `String`, and numeric identifiers when it is a `Long`.

== Bookmarks

The sessions opened on a driver share its bookmark manager, so a session sees the writes of the sessions before it, including on a cluster where reads are routed to other members. Set `micronaut.data.neo4j.bookmarks` to `false` to let each session read without waiting for earlier writes.

== Several drivers

The driver of Micronaut Neo4j is named `default`. More drivers are configured under `micronaut.data.neo4j.drivers`, and a repository names the driver it uses:

[configuration]
----
neo4j:
  uri: bolt://localhost:7687
micronaut:
  data:
    neo4j:
      database: movies
      drivers:
        archive:
          uri: bolt://archive:7687
          username: neo4j
          password: secret
      databases:
        archive: films
----

snippet::example.ArchivedMovieRepository[project-base="doc-examples/neo4j-example", source="main", tags="repository", languages="java,kotlin,groovy,python"]

<1> The repository runs on the `archive` driver. Repositories without a name use the `default` driver.

`micronaut.data.neo4j.databases.<name>` selects the database of a configured driver. Transactions are started on a driver by the api:data.neo4j.transaction.Neo4jTransactionOperations[] bean of the same name.

== Multi-tenancy

With the multi-tenancy mode `DATASOURCE`, the tenant names the driver repositories use. With the mode `SCHEMA`, the tenant names the database: each session is opened on the database of the current tenant, which needs a Neo4j edition with several databases.
