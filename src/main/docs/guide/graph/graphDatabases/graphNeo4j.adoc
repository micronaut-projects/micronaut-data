The `micronaut-data-neo4j` module runs Cypher with the https://neo4j.com/docs/java-manual/current/[Neo4j Java driver], whose `Driver` bean comes from https://micronaut-projects.github.io/micronaut-neo4j/latest/guide/[Micronaut Neo4j].

dependency:io.micronaut.data:micronaut-data-neo4j[]

Repositories are annotated with ann:data.neo4j.annotation.Neo4jRepository[].

Each operation runs in the Neo4j transaction of the current Micronaut transaction, started with `@Transactional` or api:data.neo4j.transaction.Neo4jTransactionOperations[]. Without one, each operation runs as an auto-commit query in a session opened for it. The database defaults to the default database of the server, `micronaut.data.neo4j.database` selects another.

Identifiers generated by Neo4j are element identifiers when the identity is a `String`, and numeric identifiers when it is a `Long`.
