The query language is one of:

`PGQL`:: The default. Queries are compiled to https://pgql-lang.org[PGQL] and need a data source that uses the PGQL JDBC driver from `com.oracle.database.graph:opg-pgql-jdbc`. Path finders fail at build time: they bind their endpoints as parameters, and Oracle documents that a PGQL path query with bind variables fails on a property graph in the database.
`SQL_PGQ`:: Queries are compiled to SQL/PGQ `GRAPH_TABLE` queries, which run on any Oracle Database 23ai data source. Path finders check for paths and count them, with `existsPath` and `countPaths`, and a path finder that returns paths fails at build time. `StartsWith`, `EndsWith` and `Contains` are supported through `LIKE`.

Property graphs over tables are read only views: write the tables with a JDBC repository, for example a ann:data.jdbc.annotation.JdbcRepository[] over the same entities. Path finders need a maximum depth set with ann:data.graph.annotation.PathLimit[], either on the method or on an `int` parameter, whose argument is capped by `micronaut.data.graph.max-path-depth` as described in <<graphPaths, Paths and Shortest Paths>>. Relationship finders need a single relationship type.
