To use Micronaut Data with Neo4j, add the graph annotation processor and the Neo4j module to your build:

dependency:io.micronaut.data:micronaut-data-graph-processor[scope="annotationProcessor"]

dependency:io.micronaut.data:micronaut-data-neo4j[]

NOTE: For Kotlin use `kapt` or `ksp` for the processor. For Groovy add it as a `compileOnly` dependency. For Python, which Micronaut Data supports through https://pyronaut.io[Pyronaut], add it as an `implementation` dependency: the Python compiler uses the compile classpath as its annotation processor path.

The Neo4j driver is provided by https://micronaut-projects.github.io/micronaut-neo4j/latest/guide/[Micronaut Neo4j], so configure the connection with `neo4j.uri`. With https://micronaut-projects.github.io/micronaut-test-resources/latest/guide/[Micronaut Test Resources] a Neo4j container is started for tests and development automatically.

[configuration]
----
neo4j:
  uri: bolt://localhost:7687
----
