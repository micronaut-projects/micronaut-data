To use Micronaut Data with https://age.apache.org[Apache AGE], add the AGE module to your build, along with the <<graphQuickStart, graph annotation processor>>, a connection pool and the PostgreSQL JDBC driver:

dependency:io.micronaut.data:micronaut-data-postgres-age[]

dependency:io.micronaut.sql:micronaut-jdbc-hikari[scope="runtimeOnly"]

dependency:org.postgresql:postgresql[scope="runtimeOnly"]

The graph is stored in PostgreSQL and queried through a JDBC data source. Name the graph with `micronaut.data.age.graph`. It is created when it does not exist:

With https://micronaut-projects.github.io/micronaut-test-resources/latest/guide/[Micronaut Test Resources], set `test-resources.containers.postgres.image-name` to an Apache AGE image, such as `apache/age:release_PG16_1.5.0`, to start a PostgreSQL container with AGE installed for tests and development. `create-extension` runs `CREATE EXTENSION age`, which needs a privileged user.
