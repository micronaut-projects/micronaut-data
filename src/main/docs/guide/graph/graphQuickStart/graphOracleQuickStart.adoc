To use Micronaut Data with property graphs in Oracle Database 23ai, add the Oracle graph module to your build, along with the <<graphQuickStart, graph annotation processor>>, a connection pool and the Oracle JDBC driver:

dependency:io.micronaut.data:micronaut-data-oracle-graph[]

dependency:io.micronaut.sql:micronaut-jdbc-hikari[scope="runtimeOnly"]

dependency:com.oracle.database.jdbc:ojdbc11[scope="runtimeOnly"]

Annotate a class with ann:data.graph.annotation.Node[] to map the vertices of a label to their vertex table:

snippet::example.Account[project-base="doc-examples/oracle-graph-example", source="main", tags="account", languages="java,kotlin,groovy,python"]

<2> The key of the vertex table is the identifier.
<3> The `TRANSFERS` edges that leave the account.

The edges carry an amount, so they are mapped by a class annotated with ann:data.graph.annotation.RelationshipProperties[]:

snippet::example.Transfer[project-base="doc-examples/oracle-graph-example", source="main", tags="transfer", languages="java,kotlin,groovy,python"]

Then define a repository annotated with ann:data.oracle.graph.annotation.OracleGraphRepository[]:

snippet::example.BankGraph[project-base="doc-examples/oracle-graph-example", source="main", tags="repository", languages="java,kotlin,groovy,python"]

<1> The repository queries the `bank_graph` property graph with SQL/PGQ.
<2> `CrudRepository` provides the usual create, read, update and delete operations, which write the vertex table with SQL.
<3> A finder that traverses the `TRANSFERS` edges.
<4> A path finder, which needs a maximum depth.
