Micronaut Data Nitrite is an embedded, document-oriented datastore implementation backed by https://nitrite.dizitart.org/[NitriteDB].

It supports common Micronaut Data repository patterns, including:

- <<nitriteRepositories, Repositories>>
- <<nitriteConfiguration, Configuration>>
- <<transactions, Transactions>> (via Micronaut Data TX infrastructure)

Nitrite is intended for practical embedded use-cases and basic Micronaut Data CRUD. It is not a feature-equivalent MongoDB replacement; see <<nitriteLimitations>>.
