== Configuration

Nitrite configuration is bound from `nitrite.*` properties.

The following settings are supported:

- `nitrite.db-path`: Path to the database file. If not provided and `storage-mode` is `MVSTORE`, an in-memory database is created.
- `nitrite.storage-mode`: The storage engine to use. Supported values are:
    * `MVSTORE`: (Default) MVStore-backed persistent database.
    * `IN_MEMORY`: Pure in-memory database.
    * `ROCKSDB`: RocksDB-backed persistent database.
- `nitrite.field-separator`: The character used to separate nested fields in query strings (default: `.`).
- `nitrite.username`: Optional username (for authenticated databases).
- `nitrite.password`: Optional password.

Example:

[source,yaml]
----
nitrite:
  storage-mode: MVSTORE
  db-path: /data/myapp.db
  field-separator: "."
  username: admin
  password: secret
----

To use the `ROCKSDB` storage mode, ensure you have the `nitrite-rocksdb-adapter` dependency in your project.
