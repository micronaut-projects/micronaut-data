Nitrite entities are standard Micronaut Data entities (see <<shared, Shared Concepts>>), with a few Nitrite-specific considerations:

- Nitrite stores documents internally with reserved fields (for example `_id`, `_revision`, `_modified`). The Micronaut Data Nitrite implementation avoids mapping your entity identifier to Nitrite’s internal `_id`.
- The default identifier field used by Micronaut Data Nitrite is `id`.
