== ID Generation

Micronaut Data Nitrite supports simple identifier generation using ann:data.annotation.GeneratedValue[].

When ann:data.annotation.GeneratedValue[] is present on the identity property, the Nitrite runtime assigns an identifier before insert:

- `String`: UUID string
- `java.util.UUID`: UUID
- `Long` / `long`: timestamp-based (`System.currentTimeMillis()`)
- `Integer` / `int`: timestamp-based (modulo `Integer.MAX_VALUE`)
