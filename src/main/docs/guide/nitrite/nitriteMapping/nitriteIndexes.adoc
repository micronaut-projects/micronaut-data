== Automated Index Creation

Micronaut Data Nitrite automatically creates indexes based on standard Micronaut Data annotations.

You can define indexes at the class level or property level using ann:data.annotation.Index[] or ann:data.annotation.Indexes[].

=== Primary Key Index

The identity property (mapped to the `id` field) is automatically indexed with a unique index to ensure optimal lookup performance.

=== Full-text and Spatial Indexes

Nitrite-specific indexes can be declared with ann:data.nitrite.annotation.FullTextIndex[] and ann:data.nitrite.annotation.SpatialIndex[].

Use `@FullTextIndex` on string fields that should be queried with Nitrite's `$text` filter in JSON `@Query` methods.

Spatial indexes are covered in <<nitriteSpatial>>.

=== Configuration

Automatic index creation can be disabled by setting `nitrite.create-indexes` to `false` in your application configuration.
