== Index mapping

When `micronaut.data.search.create-indexes` is enabled, Micronaut Data creates the index of a `@Searchable` entity on startup with an explicit mapping for its search fields; every other string, enum and UUID property is a `keyword`, so the derived queries compare it exactly, and the remaining properties are mapped dynamically by the store:

|===
|`@SearchField` type |Mapping

|`TEXT` |`text` with the language analyzer, plus a `keyword` sub-field (`<field>.keyword`) used for exact matches and sorting
|`KEYWORD` |`keyword`
|`AUTOCOMPLETE` |`search_as_you_type` with the language analyzer
|===

`@SearchField(analyzer = "...")` overrides the analyzer of one field with any analyzer the index defines. For settings and analyzers beyond this mapping, create the index with your own tooling before the application starts; an existing index is left untouched.

== Ids

The document id is the entity id. A `String` id left `null` is generated by the store; a `UUID` id is generated by Micronaut Data; numeric ids must be assigned by the application. The id is also kept in the document source under its property name.
